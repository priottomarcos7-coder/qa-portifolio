# Portfolio Highlights

## Main Project — REST API Test Automation

### Reading Hub — API Testing

REST API test automation project built with Cypress and JavaScript.

Positive and negative scenarios were covered, including HTTP status codes, API responses, and business rules using **GET, POST, PUT, and DELETE** operations.

**Technologies:** Cypress, JavaScript, REST API, Git, and GitHub.

**Key skills demonstrated:**
- API test automation
- Response validation
- Positive and negative testing
- Business rule validation
- Test organization and maintenance

[View the project](https://github.com/priottomarcos7-coder/hub-de-leitura-api-teste)

## E2E Project — Swag Labs with Cypress

Hands-on end-to-end automation project for a demo online store, with positive and negative scenarios for login, cart, and checkout.

**Technologies:** Cypress, JavaScript, Node.js, npm, and GitHub Actions.

**Project highlights:**
- 9 automated login, cart, and checkout scenarios
- Page Object pattern for test organization
- HTML report showing the result of each scenario
- Automatic screenshots when a test fails in headless mode
- Continuous execution through GitHub Actions, with downloadable result artifacts

[View the project and execution instructions](https://github.com/priottomarcos7-coder/cypress-swag-labs)
